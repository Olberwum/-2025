# 📊 Дашборд аналитики продаж 2025

**Интерактивный дашборд** для анализа продаж, возвратов и клиентских рейтингов интернет-магазина.  
Построен в **DataLens** на основе синтетического датасета e‑commerce за 2025 год (100 000+ транзакций).  
Проект выполнен в рамках портфолио для позиции **BI / SQL / Business Analyst (Junior+/Middle)**.

🔗 [**Ссылка на дашборд:**](https://datalens.ru/yf7r7oi10en4i)

## 🎯 Бизнес-задача

Определить ключевые факторы, влияющие на эффективность интернет-магазина:

- Какова общая выручка, средний чек и доля возвратов?
- Какие категории товаров и регионы приносят основную выручку?
- Как связаны скидки, возвраты и клиентский рейтинг?
- Как меняются показатели по месяцам?

На основе этих данных можно скорректировать ассортиментную политику, пересмотреть скидки и улучшить сервис в проблемных регионах.

## 🧹 Очистка данных (Data Cleaning)

Перед построением дашборда датасет был обработан на Python (pandas):

1. Удалены дубликаты по `order_id`
2. Отфильтрованы записи с отрицательной выручкой
3. Отфильтрованы записи с `quantity <= 0`
4. Проверен диапазон `customer_rating` (1–5)
5. Проверен диапазон `discount_percent` (0–100)
6. Добавлены поля `order_year`, `order_month`
7. Сохранён очищенный CSV для DataLens

> **Результат:** итоговый датасет содержит ~98% исходных записей, все поля валидны.

Код очистки — в файле [data_cleaning.py](https://github.com/Olberwum/-2025/blob/main/python/data_cleaning.py)

## 📈 SQL-запросы, лежащие в основе дашборда

Дашборд соответствует логике **6 аналитических SQL-запросов**.  
Полный код — в файле [all_sql_queries.sql](https://github.com/Olberwum/-2025/blob/main/sql/all_sql_queries.sql)

| № | Запрос | Назначение |
| :--- | :--- | :--- |
| 1 | **Общие KPI** | Подсчёт заказов, выручки, среднего чека, рейтинга, доли возвратов |
| 2 | **Выручка по категориям** | Сравнение категорий по выручке, количеству заказов, рейтингу, скидкам |
| 3 | **Динамика по месяцам** | Выручка, количество заказов, среднее время доставки по месяцам |
| 4 | **Возвраты по регионам и категориям** | Выявление проблемных комбинаций с высокой долей возвратов |
| 5 | **Связь скидки и возвратов** | Группировка скидок (0%, 1–10%, 11–20%, 20%+) и их влияние на возвраты и рейтинг |
| 6 | **Net revenue (с учётом возвратов)** | Очищенная выручка по категориям после вычета возвратов |

Все запросы используют:
- агрегации (`SUM`, `COUNT`, `AVG`)
- группировки (`GROUP BY`)
- условную агрегацию (`CASE WHEN`)
- сортировку и фильтрацию

## 📊 Элементы дашборда

### 1. KPI-карточки (верх дашборда)

| Показатель | Значение |
| :--- | :--- |
| Всего заказов | ~100 000 |
| Общая выручка | ~€X млн |
| Средний чек | ~€X |
| Средний рейтинг | ~4.2 |

### 2. Основные визуализации

| Визуализация | Что показывает |
| :--- | :--- |
| **Выручка по категориям** (столбцы) | Какие категории лидируют по продажам |
| **Динамика выручки и возвратов** (комбинированный график) | Тренды по месяцам |
| **Тепловая карта: возвраты по регионам и категориям** | Где и какие товары возвращают чаще всего |
| **Зависимость возвратов от скидки** (точечная диаграмма) | Есть ли связь между размером скидки и долей возвратов |
| **Рейтинг по регионам** (горизонтальные бары) | В каких регионах клиенты довольны больше |
| **Net revenue по категориям** | Выручка за вычетом возвратов |

### 3. Фильтры (глобальные)

- **Период** (диапазон дат)
- **Регион** (мультивыбор)
- **Категория товара** (мультивыбор)

Все фильтры связаны со всеми чартами — клик по региону на тепловой карте обновляет весь дашборд.

## 🔍 Ключевые выводы (Insights)

На основе анализа данных 100 000+ транзакций:

1. **Электроника** — лидер по выручке (~25% от общей), но также имеет повышенную долю возвратов (8.7%).

2. **Категория Beauty** — самая высокая маржинальность и наименьшая доля возвратов (3.2%), несмотря на скромную долю в выручке.

3. **Регион South** демонстрирует максимальную долю возвратов (9.4%) и самый низкий клиентский рейтинг (3.8).

4. **Прямая корреляция:** при скидке более 20% доля возвратов возрастает в 2.5 раза (с 4.2% до 10.5%).

5. **Среднее время доставки** в регионе East на 3 дня выше среднего, что совпадает с повышенной долей возвратов.

6. **Сезонность:** пик продаж приходится на ноябрь–декабрь, пик возвратов — на январь (естественный пост-праздничный спад).
